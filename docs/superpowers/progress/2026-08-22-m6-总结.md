1. **知识利用率用 view_count**：问答命中时累加被引用知识的 `view_count`，统计页按此排序。原 `view_count` 字段（M2 定义但未用）现在真正生效。

4. **备份脚本**：pg_dump + 从 backend 容器 tar 附件，输出到 `backups/` 目录。
5. **加 .gitattributes**：统一 LF 换行，避免 Windows 开发 / Linux 部署换行符不一致（尤其 .sh 脚本）。
