## 🔀 关键决策与偏离

1. **数据库从 Docker 改为本机原生 PostgreSQL 16**：`wsl --install` 下载 Ubuntu 卡 0%（国内网络连不上微软 CDN），放弃 Docker/WSL 路线。本机安装 PostgreSQL 16 到 `D:\PostgreSQL\16`（服务 `postgresql-16`），创建角色 `aiqa`（带 CREATEDB）与库 `aiqa`。部署阶段（M5）仍交付 docker-compose，开发与部署形态解耦。
2. **pgvector 延后到 M3**：M1 只需关系型表，向量检索到问答引擎（M3）才需要。
3. **后端改用 venv 虚拟环境**：系统 Python 目录（`D:\Python312`）不可写，`pip install` 会权限失败；创建 `backend/.venv`，所有后端命令走 `backend\.venv\Scripts\python.exe`。
4. **Task 4 计划 bug 修正**：① 错误密码测试用例 `"wrong"`（5 字符）会触发 pydantic min_length 422 而非 401，改为 `"wrong1"`；② 计划声明 8 个测试但只列 7 个，补充 `test_login_disabled_account`。
5. **Task 7 健壮性修复**：① 登录失败（401）无用户反馈 → 在 `/login` 页弹错误提示；② 守卫 fetchMe 失败仅跳登录不清 token → 先 logout 再跳转。
6. **Home.vue 死代码清理**：Task 6 的占位页被 Task 8 的 Dashboard 取代，已删除。

## 🔌 接口变更清单（供 M2 及后续里程碑引用）

**后端（FastAPI，`/api` 前缀）**：
- `GET /api/health` → `{status, mode}`（mode = full|public）
- `POST /api/auth/register`（仅 public 模式，角色固定 support）
- `POST /api/auth/login` → `{access_token, token_type, user}`
- `GET /api/auth/me` → UserOut
- `GET /api/users`（admin）、`POST /api/users?role=...`（admin，full 模式）、`PATCH /api/users/{id}`（admin）

**后端模块（供 M2 复用）**：
- `app.config.settings`（pydantic-settings，含 APP_MODE/DATABASE_URL/SECRET_KEY 等）
- `app.db.Base` / `app.db.get_db`
- `app.core.security`：`hash_password`/`verify_password`/`create_access_token`/`decode_token`
- `app.core.deps`：`get_current_user` / `require_roles(*roles)`
- `app.models.User`（users 表）/ `ROLES = ("engineer","support","admin")`
- `app.schemas.user`：`UserCreate`/`UserOut`/`UserUpdate`/`Token`

**前端（Vue3，`/api` 走 Vite 代理）**：
- `src/api/http.js`：axios 实例（自动带 Bearer token、401 处理、错误 ElMessage）
- `useAuthStore`（token/user/isAdmin/isEngineer/login/register/fetchMe/logout）
- `useAppStore`（mode 默认空串/isPublic/isFull/fetchHealth）
- `src/layouts/MainLayout.vue`：按 mode 渲染菜单（公网 3 项 / 内网 6 项 + admin 用户管理）
- 路由：`/`（Dashboard）、`/login`（public）、`/chat`、`/knowledge`、`/tickets`、`/manage`、`/review`、`/admin/users`（占位，后续里程碑实现）

**数据库**：
- `aiqa` 库 + `aiqa` 角色（密码 `aiqa_dev_password`，带 CREATEDB）
- `users` 表（alembic 迁移已应用，迁移文件 `backend/alembic/versions/1292ef54ea51_create_users_table.py`）

## 📋 遗留项（Minor，留待最终 review / 后续里程碑）

1. `conftest.py` 的 `except Exception: pass` 吞异常（Task 2，源自计划）
2. `main.py` CORS `allow_origins=["*"]` + `allow_credentials=True`（开发宽松，M5 收紧）
3. pydantic `class Config` 弃用警告（建议统一迁移 `SettingsConfigDict`）

6. login 复用 `UserCreate`（含注册级校验），建议独立 `LoginRequest` schema

8. **新建用户 `group_name` 被静默丢弃**（前端收集但 POST 未提交 + 后端 UserCreate 无此字段），建议 UserCreate 加 group_name（Task 9 简报层缺口）
9. 前端表单无校验，依赖后端报错
10. token 存 localStorage 的 XSS 风险（简报指定设计）
