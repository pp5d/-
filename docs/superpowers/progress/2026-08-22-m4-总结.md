## 🔀 关键决策与偏离

1. **通知机制简化**：不做独立站内消息系统，通过工单列表状态体现"通知"（engineer 在处理台看到新工单，support 在"我的工单"看到答复）。YAGNI，后续需要再做消息推送。
2. **未命中建单时机**：qa 接口在 `hit=False` 且 `allow_free=False` 时自动建单；`allow_free=True`（用户主动选择自由回答）不重复建单（第一次已建）。
3. **一键沉淀为知识**：工单答复转知识草稿（title=question 截断 200 字、kind=qa、body=answer、aliases=[question]），工程师可在知识管理里完善后发布。
4. **确认框取消 bug（系统性修复）**：发现 `.catch(() => {})` 吞掉取消 reject 导致"取消仍执行操作"的 bug，修复了 3 处（工单关闭 + 知识下架 + 知识删除），改为 try/catch + 取消 return。
