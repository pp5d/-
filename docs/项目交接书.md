## 技术栈

- 后端：FastAPI + SQLAlchemy 2.0 + PostgreSQL 16（`D:\PostgreSQL\16`）+ Alembic
- 向量：本地 bge-small-zh-v1.5（512 维，模型缓存 `backend/data/hf_cache`，经 hf-mirror 下载）
- 生成：DeepSeek API（key 在 `backend/.env`）
- 前端：Vue3 + Element Plus + Pinia + Vue Router（`frontend/`）
- 部署：Docker Compose（`docker-compose.yml`）
