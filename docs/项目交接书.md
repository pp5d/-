### 2. 降低 token 成本：本地小模型回答 + API 分级

**现状**：所有回答都调 DeepSeek API（有 token 成本）。

**探索方向：分级问答策略**
- **简单/常规问题** → 本地小模型回答（零边际成本）
- **深层次/复杂问题** → 调 DeepSeek API（保证质量）
- 判断"简单 vs 复杂"的方式：问题长度/关键词/意图分类/检索置信度/小模型自评

**本地小模型技术选型（供探索）**：
- 部署工具：**Ollama**（一条命令跑本地模型，最省事）或 vLLM（高性能）
- 模型候选：
  - `Qwen2.5-7B-Instruct`：中文强，需约 8GB 显存（无 GPU 可 CPU 慢跑）
  - `Qwen2.5-3B`：轻量，普通电脑 CPU 可跑
  - `DeepSeek-R1-Distill-Qwen-1.5B/7B`：推理能力好（注塑机问题偏推理排查，值得试）
- 接入方式：Ollama 提供 OpenAI 兼容 API，后端 `services/llm.py` 可加一个"本地模型优先、API 兜底"的分级路由

**成本对比**：DeepSeek API 约 1 元/百万 token（很便宜），但高频使用有成本；本地小模型零边际成本，且数据完全不出内网。
