# 验收走查清单

> 用途：部署后逐条走查，确认系统功能正常。建议由工程师 + 售后各走一遍。

## 0. 前置
- [ ] 已完成部署（内网实例），浏览器能打开登录页
- [ ] 已运行种子脚本（`docker compose exec backend python seed.py`）
- [ ] 已创建 admin 账号

## 1. 登录与权限
- [ ] admin 登录成功，左侧菜单含"用户管理/统计报表"
- [ ] 新建一个 engineer 账号，engineer 登录后能看到"知识管理/审核中心/工单处理"
- [ ] （公网）注册一个 support 账号，只能看到"智能问答/知识库/我的工单"

## 2. 知识管理
- [ ] 新建知识（问答对/文章/故障案例/代码表格四种类型都能建）
- [ ] 问法别名、Markdown 正文、分类、适用机型能正常保存
- [ ] 草稿能提交审核，审核中心能通过/退回
- [ ] 已发布知识能"发布公网"、能"下架"
- [ ] 草稿能"删除"，已发布内容不能删除（只能下架）

## 3. 智能问答
- [ ] 问"模保是什么"→ 命中，返回回答 + 可点击来源"模保功能原理"
- [ ] 问一个知识库没有的问题 → 提示未找到 + "用 AI 通用知识回答"按钮
- [ ] 点"用 AI 通用知识回答"→ 返回带"未经验证"标注的回答
- [ ] 切换页面再回来，聊天记录还在（最多 30 条）

## 4. 工单闭环
- [ ] 问未命中的问题 → 自动建工单，提示"已转交工程师"
- [ ] engineer 在"工单处理"看到工单，答复
- [ ] 答复后点"沉淀为知识"→ 生成知识草稿
- [ ] 在知识管理完善草稿、发布后，再问同类问题能命中

## 5. 管理后台
- [ ] 统计页能看到总览卡片、高频问题、知识利用率、工单响应
- [ ] （公网阶段）点"同步到公网"能成功推送

## 6. 权限与安全
- [ ] support 看不到知识管理/审核中心/工单处理/用户管理/统计
- [ ] support 无法审核知识、无法答复工单（后端 403）
- [ ] 未登录访问任何页面跳转登录

## 7. 其他
- [ ] 附件上传图片/PDF 成功，下载正常
- [ ] 提问限流生效（连续提问超 10 次/分钟返回 429）
