# 公网实例部署文档（APP_MODE=public）

> **依赖内网**：公网是只读问答门户，知识靠内网同步推送。请先完成内网部署（见《内网部署.md》），再部署公网。

## 前置
- 服务器：有公网 IP/域名，已装 Docker + Docker Compose
- 开放端口：80（或 443 经反向代理）

## 步骤
1. 上传项目代码到服务器
2. 在项目根目录创建 `.env` 文件：

```ini
# ===== 必填 =====
APP_MODE=public
SECRET_KEY=强随机字符串（必填，否则容器起不来）
DEEPSEEK_API_KEY=你的DeepSeek平台key
POSTGRES_PASSWORD=数据库密码
PUBLIC_API_TOKEN=与内网一致的同步令牌
```

3. 启动：`docker compose up -d --build`
4. 访问：http://公网IP，售后/试机可自行注册（角色固定 support）
5. 回内网配置 `PUBLIC_SYNC_URL` 和 `PUBLIC_API_TOKEN`，触发首次同步

## 安全说明（上线必选）
- **HTTPS 必选**：同步 Token 与登录凭据不可明文传输，必须在公网实例前置 nginx/云负载均衡做 HTTPS（证书终止）。
- **IP 白名单必选**：同步接口 `/api/sync/import` 只允许内网实例的出口 IP 访问（在负载均衡/防火墙配置）。
- 公网实例代码层面禁用知识写操作与管理接口（仅接收同步端点，Token 保护）。
- 提问接口已限流（每用户每分钟 10 次）。
