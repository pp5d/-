# 内网实例部署文档（APP_MODE=full）

> **分阶段部署**：内网可完全独立部署（公网是后加的可选组件）。第一阶段先只部署内网给工程师内部测试，稳定后再按"同步到公网"章节接公网。内网不依赖公网，任何功能都不受影响。

## 前置
- 服务器：Linux/Windows，已装 Docker + Docker Compose
- 开放端口：80（前端）、8000（后端，仅内网）

## 步骤
1. 上传项目代码到服务器
2. 在项目根目录创建 `.env` 文件（docker compose 自动读取），内容如下：

```ini
# ===== 必填 =====
APP_MODE=full
SECRET_KEY=强随机字符串（必填，否则容器起不来）
DEEPSEEK_API_KEY=你的DeepSeek平台key
POSTGRES_PASSWORD=数据库密码

# ===== 第一阶段（只部署内网）可留空 =====
PUBLIC_API_TOKEN=
PUBLIC_SYNC_URL=
```

3. 启动：`docker compose up -d --build`
4. 首次访问：浏览器打开 http://服务器IP
5. 创建管理员：`docker compose exec backend python -c "from app.db import SessionLocal; from app.models.user import User; from app.core.security import hash_password; db=SessionLocal(); db.add(User(username='admin', role='admin', hashed_password=hash_password('admin123'))); db.commit()"`（务必改掉 admin123）
6. 用 admin 登录，创建其他账号

## 同步到公网（第二阶段，稳定后再做）
1. 先在公网服务器部署公网实例（见《公网部署.md》），得到公网地址和同步令牌
2. 回内网，把 `.env` 里两项补上：
   - `PUBLIC_API_TOKEN=与公网一致的令牌`
   - `PUBLIC_SYNC_URL=http://公网IP/api/sync/import`
3. 重启后端：`docker compose up -d`（重新加载环境变量）
4. 在内网知识里勾选"发布公网"，触发同步（M6 管理后台提供同步按钮，在此之前可调 `POST /api/sync/push` 接口）
