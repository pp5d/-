# 内网实例部署文档（APP_MODE=full）

## 前置
- 服务器：Linux/Windows，已装 Docker + Docker Compose
- 开放端口：80（前端）、8000（后端，仅内网）

## 步骤
1. 上传项目代码到服务器
2. 配置环境变量（.env 或直接改 docker-compose.yml）：
   - SECRET_KEY：强随机字符串
   - DEEPSEEK_API_KEY：DeepSeek 平台 key
   - PUBLIC_API_TOKEN：与公网实例一致的同步令牌
   - 若不需要同步，PUBLIC_API_TOKEN 可留空
3. 启动：`docker compose up -d --build`
4. 首次访问：浏览器打开 http://服务器IP
5. 创建管理员：`docker compose exec backend python -c "from app.db import SessionLocal; from app.models.user import User; from app.core.security import hash_password; db=SessionLocal(); db.add(User(username='admin', role='admin', hashed_password=hash_password('admin123'))); db.commit()"`（改掉 admin123）
6. 用 admin 登录，创建其他账号

## 同步到公网
- 配置 backend 环境变量 PUBLIC_SYNC_URL=http://公网IP/api/sync/import
- 管理员登录后，调用同步接口（后续管理后台提供按钮）或：`docker compose exec backend python -c "import httpx; from app.config import settings; ..."`（M6 提供管理后台按钮）
